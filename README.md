# 氯化钙买家线索采集器

这是一个面向中国市场的本地小工具，用来批量生成和筛选氯化钙潜在买家线索。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/changyitian000421-ship-it/Yves)

## 能做什么

- 按地区和下游行业批量生成买家开发清单
- 支持高德 Web 服务 API Key，自动采集企业/门店名称、电话、地址
- 按氯化钙应用场景自动评分，比如融雪剂、干燥剂、水处理、钻井液、混凝土外加剂、冷库制冷、化工贸易
- 支持 4 路并发采集和快速模式，减少批量查询等待时间
- 实时显示采集百分比、请求进度、企业数量和含电话数量
- 查看企业公开详情，包括别名、电话、邮箱、官网、地址、行业类型、坐标、POI ID 和数据更新时间
- 自动生成匹配原因和销售跟进重点
- 加入招采/采购关键词监控入口
- 导出 Excel 可打开的 CSV 文件

## 本地启动

```bash
APP_PASSWORD=你的登录密码 \
AMAP_KEY=你的高德Web服务Key \
SESSION_SECRET=一段随机长字符串 \
python3 app.py
```

打开浏览器访问：

```text
http://127.0.0.1:8765
```

访问后先输入 `APP_PASSWORD` 登录。登录状态有效期为 12 小时。

## 部署成固定网站

项目包含 `Dockerfile` 和 `render.yaml`，可以部署到 Render：

1. 将项目推送到 GitHub 仓库。
2. 在 Render 创建 Blueprint，选择该仓库。
3. 填写环境变量 `APP_PASSWORD` 和 `AMAP_KEY`。
4. `SESSION_SECRET` 会由 Render 自动生成。
5. 部署成功后即可获得固定的 HTTPS 地址。

不要把密码或高德 Key 写进 Git 仓库。高德 Key 只保存在云平台环境变量中。

## 高德 API Key

服务器未配置 Key 时，仍可生成“开发任务清单”，但不能采集具体公司和电话。

配置高德 Web 服务 API Key 后，工具会调用高德 POI 搜索接口，批量返回公司名、电话、地址、行业类型等信息。

共享网站会统一使用服务器上的 Key，普通用户无法在页面源代码中看到它。

## 推荐使用方法

1. 先选择 `东北`、`华东`，行业选择 `融雪剂/除冰剂`、`干燥剂/吸湿材料`、`化工贸易商/经销商`。
2. 采集页数先设为 `1`，确认结果质量后再加大。
3. 导出 CSV，用电话或搜索链接逐个核验。
4. 对 70 分以上线索优先跟进，先问用途、规格、年用量、现供应商、付款和发货地区。

“快速模式”默认每个行业使用两个高价值关键词，适合日常初筛。关闭快速模式后会使用完整关键词库，覆盖更多企业，但耗时和高德额度消耗也会增加。

服务器默认使用 4 路并发，可通过 `AMAP_WORKERS` 调整为 `1-8`。不建议超过 `8`，以免触发接口限流。

企业详情来自高德公开 POI 数据。法人、注册资本、成立日期、经营状态等工商字段需要另行接入持牌工商数据服务。
