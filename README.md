# 液体氯化钙产业信息与销售工作台

这是一个面向中国市场的液体氯化钙业务系统，用来发现买家、液钙副产货源、
招采需求和相关环保工艺企业，并持续管理销售跟进。

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/changyitian000421-ship-it/Yves)

## 能做什么

- 按地区和下游行业批量生成买家开发清单
- 独立“全国分省企业名录”模式：覆盖 34 个省级行政区、393 个逐城检索单元；选择任意省份后自动展开所属地市，汇总处理厂和企业名称、公开电话、地址与来源
- 省级结果按城市统计，可点击城市筛选、查看联系方式覆盖率，并按当前筛选导出；无公开电话的真实企业也会保留
- 内置污水处理厂、工业园区污水厂、自来水厂、危废固废、垃圾焚烧、环保服务、化工和制药等省级名录模板
- 支持高德、百度和天地图服务端 API，自动采集企业名称、电话、地址并跨来源合并
- 首页醒目显示百度千帆、Brave Search、Hunter、高德、百度地图、天地图和短信服务的今日用量、总量、余量与分级预警
- Brave Search 作为企业官网发现回退源；候选官网必须再次打开原页面核验后才会写入线索，不保存 Brave 搜索摘要
- Hunter 自动为每次采集中最高优先级且缺邮箱的少量企业补全带公开来源页面的企业邮箱，相同企业缓存 30 天
- Brave 每月最多 1000 次、Hunter 每月最多 50 次的免费保护上限写死在程序中，到顶自动停止，页面只能调整更细的每日额度
- 按氯化钙应用场景自动评分，比如融雪剂、干燥剂、水处理、钻井液、混凝土外加剂、冷库制冷、化工贸易
- 支持 4 路并发采集和快速模式，减少批量查询等待时间
- 实时显示采集百分比、请求进度、企业数量和含电话数量
- 查看企业公开详情，包括别名、电话、邮箱、官网、地址、行业类型、坐标、POI ID 和数据更新时间
- 自动生成匹配原因和销售跟进重点
- 独立招投标/采购监控模式
- 自动聚合全国公共资源交易平台、中国政府采购网和中央政府采购网
- 招采结果以采购单位为主档，同一公司来自多个平台和多条公告时自动合并电话、来源和证据数量
- 官方平台无具体公告时不再把关键词搜索入口伪装成公司线索；企业官网核验默认开启
- 覆盖中国政府采购网的中央公告及省级地方政府采购公告栏目
- 可选“企业官网”来源：先定位目标公司，再检查官网采购、招标、询价和供应商公告
- 招采主题中单独提供“液体氯化钙”选项
- 提取采购单位电话、地址、项目联系人、代理机构、预算和截止时间
- 按采购公告、招标公告、中标/成交结果筛选
- 支持近 3 天、10 天、30 天、90 天时间窗口
- 导出 Excel 可打开的 CSV 文件
- 自动保存线索并按企业或采购项目去重
- 线索数据库与公司档案共用缓存并分页展示，避免数千条记录重复加载和一次性渲染
- 新增“今日工作台”，自动汇总逾期、今日应跟进、有需求/报价中和高潜待联系企业
- “处理下一条”按跟进时间、销售阶段、线索质量和联系方式自动排列优先顺序
- 销售漏斗和数据完善面板集中显示各阶段数量、联系方式完整度和未分配负责人数量
- 公司档案只展示已跟进、手动新增或已填写业务参数的企业，不再混入全部原始采集结果
- 提供今日待跟进、高潜待联系、未分配、新发现和待补联系方式销售工作队列
- 自动记住每个采集方向最近一次使用的地区、行业、来源和策略
- 提供“精准 / 均衡 / 广覆盖”三档采集策略，自动调整页数、关键词范围和严格程度
- 外部采购平台会先做可用性探测；遇到超时、403 或证书异常时自动跳过该来源并继续采集
- 相同查询短暂超时时自动重试一次，重复的来源错误会合并显示，避免系统记录刷屏
- 每条线索按证据强度分为 A-D 级，并显示质量依据、缺失信息和建议下一步
- 含氟废水精准模式会优先并发核验最相关许可，均衡和广覆盖模式再逐级扩大范围
- 精准模式会校验目标省市并排除商店、住宅、道路等非企业地图结果
- 重复采集使用稳定评分模型，不会因反复保存而自动涨分
- 同一企业来自多个来源的电话、邮箱和证据会自动合并保留
- 液钙专属档案：商机角色、浓度、月供/用量、杂质、运输半径、储运条件和商业价值
- 销售状态、负责人、备注、下次跟进和到期提醒
- 公司详情保留逐条跟进时间线，批量更新和单条更新都会留下可追溯记录
- 批量分配负责人、批量修改销售状态和跟进时间
- 定时监控保存的采集条件，只提醒新增线索
- 系统运行中心记录采集错误、数据源异常和关键操作
- 一键下载完整 SQLite 数据库备份
- 独立竞品/同行客户挖掘模式，聚合同行官网、1688、百度爱采购和中国化工网公开索引
- 自动提炼同行重点服务行业、地区布局、产品词、应用词和公开证据
- “反向开发”可将同行画像自动转换成下游买家采集条件
- 竞品情报支持自动去重、CSV 导出、定时监控和官网深度分析
- 独立“社媒线索雷达”，支持抖音、快手、小红书、哔哩哔哩、微博、微信公众号/视频号、今日头条和知乎
- 可批量粘贴公开分享链接，自动识别平台、账号、内容标题、命中关键词、公开电话和互动信息
- 按地区、主题和平台监控搜索引擎已经收录的公开内容，不依赖平台开放接口审批
- 社媒结果按平台区分展示，并接入现有评分、去重、详情、CSV、线索库和定时提醒
- 自动区分求购/采购、副产出售/处置、含氟废水需求、同行供应、环保工程服务和待判断内容
- 支持重点意向词和排除词；高意向内容优先排序，实验教学、招聘和零售内容可自动过滤
- 每条社媒线索可人工标记有效、无关或重复，后续自动过滤相同无效内容并提升已验证账号权重
- 自动给出企业主体候选，可在详情中修改并确认后直接沉淀为公司档案

## 全国分省企业名录

1. 在“采集方向”选择“全国分省企业名录”。
2. 从华北、东北、华东、华中、华南、西南、西北和港澳台分组中选择任意省级行政区，再选择名录类型；例如“广东 + 污水处理厂/水质净化厂”。
3. 默认使用“均衡”策略，系统会自动扫描该省全部逐城检索单元，并跨关键词、跨地图来源合并重复企业。
4. 采集完成后查看全省企业数、有联系方式数量、有公开电话数量和城市覆盖情况；点击城市即可只看该市。
5. 使用“待补电话”快速筛选需要二次核验的企业，或保存为监控，定期只提醒新增企业。

“精准”适合快速建立初步名录；“均衡”兼顾覆盖与 API 用量；“广覆盖”会增加关键词和翻页数量，适合建立省级底库。统计基于已接入地图平台的公开登记，不等同于行政许可绝对全量。地图未公开电话时，系统会保留企业名称和地址，便于后续通过官网、工商数据服务或人工核验补充。

## 社媒线索雷达

1. 在“采集方向”选择“社媒线索雷达”。
2. 选择地区、监控主题和需要覆盖的平台。
3. 直接点击“开始公开索引检索”；不需要预先准备或导入链接。
4. 如需核验指定内容，可在可选链接框中每行粘贴一个链接或直接粘贴分享文案。
5. 点击“保存为监控”，即可按所选地区、主题和平台定时发现新增公开内容。

结果详情中的“有效 / 无关 / 重复”用于训练本地规则；确认企业主体后，系统会保留
原社媒证据，同时把完整企业名称写入公司档案。人工反馈和主体确认不会发送给社媒平台。

该功能只读取无需登录的公开链接和公开搜索索引，不读取私信、评论区、登录后内容，
也不绕过验证码。社媒账号不等同于工商主体，正式联系前应核验企业名称和联系方式。

## 本地启动

```bash
APP_PASSWORD=你的登录密码 \
LOGIN_PHONES=允许登录的手机号 \
AMAP_KEY=你的高德Web服务Key \
BAIDU_MAP_AK=你的百度地图服务端AK \
TIANDITU_TK=你的天地图服务端TK \
BAIDU_SEARCH_API_KEY=你的百度千帆API_Key \
BRAVE_SEARCH_API_KEY=你的Brave_Search_API_Key \
HUNTER_API_KEY=你的Hunter_API_Key \
SESSION_SECRET=一段随机长字符串 \
SMS_DEV_MODE=1 \
DATA_DIR=./data \
python3 app.py
```

打开浏览器访问：

```text
http://127.0.0.1:8765
```

访问后使用白名单手机号、`APP_PASSWORD` 和手机验证码登录。`SMS_DEV_MODE=1`
仅用于本地测试，会在页面自动填入验证码；正式部署不要开启。登录状态有效期为 12 小时。

## 本地打不开时

本地版已经配置为 macOS LaunchAgent，会在登录后自动启动，崩溃后自动重启。

常用修复命令：

```bash
./scripts/repair_local_service.sh
```

重新安装本地守护服务：

```bash
./scripts/install_local_service.sh
```

一键修复并打开网站：

```bash
./scripts/open_local_site.sh
```

本地登录参数保存在 `~/Library/Application Support/CalciumLeads/local.env`，
服务配置保存在 `~/Library/LaunchAgents/com.yves.calciumleads.plist`。
这些文件不会提交到 Git。

百度地图 AK 可通过安全脚本配置并立即验证：

```bash
./scripts/configure_baidu_map.sh
```

脚本会隐藏输入内容，验证地点检索接口成功后才写入 `BAIDU_MAP_AK`，随后自动重启本地服务。

天地图 TK 可通过安全脚本配置并立即验证：

```bash
./scripts/configure_tianditu.sh
```

脚本使用行政区域地名搜索 V2.0 验证 TK，成功后才写入 `TIANDITU_TK`，
并自动重启本地服务。
申请时需要在天地图控制台为 TK 开通“地名搜索服务 V2.0”权限；
接口说明见 `https://lbs.tianditu.gov.cn/server/search2.html`。

百度千帆网页搜索 API Key 可通过安全脚本配置并立即验证：

```bash
./scripts/configure_baidu_search.sh
```

配置后，企业官网、环保文件、竞品页面和社媒公开索引会优先使用百度千帆
官方 JSON API；未配置或接口暂时失败时自动回退到兼容公开索引。
系统默认缓存相同查询 7 天，并将千帆调用保护在每天 45 次以内。
可通过 `BAIDU_SEARCH_CACHE_DAYS` 和 `BAIDU_SEARCH_DAILY_LIMIT` 调整。

Brave Search 和 Hunter 可通过安全脚本配置：

```bash
./scripts/configure_brave_search.sh
./scripts/configure_hunter.sh
```

Brave 只用于发现企业官网，系统会访问原官网核验企业名称后再保存网址；
Hunter 只保存带公开来源页面的企业邮箱。精准、均衡、广覆盖策略每次最多分别核验
2、3、5 家缺少邮箱的高优先级企业，避免一次采集耗尽额度。

## API 用量提醒

首页“API 用量中心”按实际发出的请求计数，网络重试也会计入。点击“设置每日总量”，
填写各平台控制台显示的每日额度后，系统会显示剩余次数和进度：

- 低于 70%：正常
- 达到 70%：橙色提醒
- 达到 90%：红色提醒
- 达到 100%：额度已用完

百度千帆默认每日保护上限为 45 次；Brave 默认每天 30 次且每月硬上限 1000 次，
Hunter 默认每天 5 次且每月硬上限 50 次。其他平台的总量因账号套餐不同，需要在页面中填写。
也可以通过 `AMAP_DAILY_LIMIT`、`BAIDU_MAP_DAILY_LIMIT`、
`TIANDITU_DAILY_LIMIT`、`ALIYUN_SMS_DAILY_LIMIT`、`BRAVE_SEARCH_DAILY_LIMIT`
和 `HUNTER_DAILY_LIMIT` 提供初始默认值。
页面保存的额度和每日用量会写入当前数据库；Render 使用 Turso 时可跨重启保留。
后续新增 API 平台只需在统一平台清单中登记，即可复用同一套计数和提醒界面。

## 部署成固定网站

项目包含 `Dockerfile` 和 `render.yaml`，可以部署到 Render：

1. 将项目推送到 GitHub 仓库。
2. 在 Render 创建 Blueprint，选择该仓库。
3. 填写环境变量 `APP_PASSWORD`、`LOGIN_PHONES`，并至少配置
   `AMAP_KEY`、`BAIDU_MAP_AK` 或 `TIANDITU_TK`；配置多个 Key 时会并行采集并合并结果。
   如需稳定的官网、环评、竞品和社媒公开页面检索，再填写
   `BAIDU_SEARCH_API_KEY`；如需备用官网发现和公开企业邮箱补全，再填写
   `BRAVE_SEARCH_API_KEY`、`HUNTER_API_KEY`。
   如需云端长期保存线索，再填写 `TURSO_DATABASE_URL` 和 `TURSO_AUTH_TOKEN`。
4. `SESSION_SECRET` 会由 Render 自动生成。
5. 开通阿里云“号码认证服务 > 短信认证”，配置：
   `ALIYUN_PNVS_ACCESS_KEY_ID`、`ALIYUN_PNVS_ACCESS_KEY_SECRET`。
   如控制台要求方案名称，再填写 `ALIYUN_PNVS_SCHEME_NAME`。
   系统默认使用短信认证服务赠送的签名 `速通互联验证码` 和模板 `100001`。
6. 部署成功后即可获得固定的 HTTPS 地址。

当前 `render.yaml` 使用 Render Starter 免费部署配置，不申请持久磁盘。
这种方式可以免费上线，但数据库保存在容器本地文件系统中；重新部署、重启或实例重建时，
线索、备注和监控任务可能丢失。正式使用前请经常在“系统运行中心”下载完整备份，
或接入 Turso 云数据库。

## Turso 云数据库

配置以下环境变量后，系统会自动从本地 SQLite 切换为 Turso 云同步模式：

```text
TURSO_DATABASE_URL=libsql://你的数据库地址
TURSO_AUTH_TOKEN=你的数据库访问令牌
```

本地不配置这两个变量时，仍然使用 `DATA_DIR` 下的 SQLite 文件。
Render 免费部署建议配置 Turso，否则重新部署后客户档案和跟进记录可能丢失。
系统运行中心会显示当前数据库模式：`本地 SQLite` 或 `Turso 云同步`。

不要把密码或地图 API Key 写进 Git 仓库。Key 只保存在本地或云平台环境变量中。
正式部署不要配置 `SMS_DEV_MODE`。验证码由阿里云生成并通过
`CheckSmsVerifyCode` 核验，网站不会保存生产验证码。

## 地图 API Key

服务器未配置地图 Key 时，仍可生成“开发任务清单”，但不能采集具体公司和电话。

配置高德 Web 服务 API Key、百度地图服务端 AK 或天地图服务端 TK 后，
工具会调用对应的 POI 地点检索接口，批量返回公司名、电话、地址和行业类型。多个 Key 同时配置时，
系统会跨来源合并同一企业的电话、地址和证据，并在单一来源失败时保留另一来源结果。

共享网站会统一使用服务器上的 Key，普通用户无法在页面源代码中看到它。

## 推荐使用方法

1. 每天先打开“今日工作台”，从“处理下一条”开始完成逾期和报价中任务。
2. 日常电话开发先用“精准”，单独选择一个省或城市和 1-2 个行业。
3. 精准结果不足时切到“均衡”；需要建立行业底库时再用“广覆盖”。
4. 优先处理 A 级，其次处理有电话或证据链接的 B 级；C 级先补官网或官方文件证据。
5. 核实企业后填写销售状态、负责人和下次跟进时间，该企业才会进入“公司档案”。
6. 详情页会列出质量依据、待补信息、建议下一步和历史跟进记录。

“快速模式”默认每个行业使用两个高价值关键词，适合日常初筛。关闭快速模式后会使用完整关键词库，覆盖更多企业，但耗时和地图 API 额度消耗也会增加。

## 竞品/同行客户挖掘

1. 选择“竞品/同行客户挖掘”，勾选产品方向和目标地区。
2. 默认聚合同行官网、1688、百度爱采购和中国化工网的无需登录公开页面。
3. 保持“定位官网并分析”开启，可补充产品、应用、案例和市场栏目中的行业词。
4. 在结果中点击“反向开发”，系统会自动切回下游买家模式并带入地区、行业和关键词。
5. 打开证据页核验后，再将高价值结果保存为监控任务。

平台页面可能存在登录、验证码、限流或改版。系统不会绕过这些限制，只使用可公开访问的页面和搜索索引；因此情报结果属于销售研究线索，不代表平台官方认证或完整客户名单。

服务器默认每个地图源使用 4 路并发，可通过 `AMAP_WORKERS`、
`BAIDU_MAP_WORKERS` 和 `TIANDITU_WORKERS` 调整为 `1-8`。
不建议超过 `8`，以免触发接口限流。

企业详情来自高德、百度和天地图公开 POI 数据。法人、注册资本、成立日期、经营状态等工商字段需要另行接入持牌工商数据服务。

## 数据维护

- 在线索数据库中维护液钙浓度、月供/用量、杂质和运输半径，评分会自动考虑液钙适配度。
- 在“系统运行”中查看采集错误和数据源健康状态。
- 定期点击“下载完整备份”。备份文件包含全部线索、销售记录、监控任务和操作日志。
- 系统自动保留最近 10 个服务器端备份文件。
